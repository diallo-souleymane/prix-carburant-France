# Suivi des prix du carburant en France

Projet Data Engineer visant à automatiser la collecte, la transformation
et la visualisation des prix du carburant en France.

## Stack
- Python (ingestion)
- SQL & dbt (transformations)
- Power BI (visualisation)
- GitHub (versioning)

## Fréquence
- Pipeline batch exécuté toutes les 24h
